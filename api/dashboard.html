                    📌 Project Overview
                

                

                    This system provides an end-to-end Machine Learning solution for Learning Management Systems (LMS).
                    It automates student code grading via software engineering defect prediction and triages incoming
                    student programming doubts into actionable topics, urgency levels, and routing decisions.
                

            


            

                
                

                    

                        Pipeline 1: Code Quality Grading
                    

                    

                        Dataset Built: NASA KC1 Software Defect Dataset (1,000+ software modules).
                        Combines McCabe cyclomatic complexity, Halstead program volume/effort metrics, and line counts.
                    

                    

                        Engineered Features:
                    

                    

                        Complexity_per_LOC
                        Branch_Density
                        Fan_Ratio
                        Complexity_x_LOC
                        Halstead_per_LOC
                    

                    

                        Model Architecture: LightGBM (Gradient Boosting) + Optuna Hyperparameter Tuning
                        + Random Forest Baseline.

                        Pipeline 2: Student Doubt Triage
                    

                    

                        Dataset Built: CS1QA Educational Programming Q&A Dataset (9,237 annotated
                        student queries across 9 question categories: syntax, logic, runtime, conceptual, output,
                        debugging, implementation, design, other).
                    

                    

                        NLP Preprocessing & Routing: Lowercasing, URL/punctuation removal,
                        Lemmatization + TF-IDF Vectorization (5000 max features, bigrams) + Heuristic Keyword Urgency
                        derivation (HIGH / MEDIUM / LOW).
